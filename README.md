# 📦 MeshalBox

**Install your favorite Windows apps in one place.**

MeshalBox is a single-file PowerShell tool that lets you browse an organized application catalog and install multiple Windows programs at once using WinGet.

## ✨ Features

- 📚 **Organized Catalog** — Browse applications by category.
- ⚡ **Batch Installation** — Install multiple applications in one go.
- 🪟 **Windows Support** — Designed for Windows 10 and Windows 11.
- 🛠️ **PowerShell-Based** — Runs from a single PowerShell script.
- 📦 **WinGet Integration** — Uses the Windows Package Manager to install applications.

## 📋 Requirements

- 🪟 Windows 10 or Windows 11
- 💻 PowerShell

## 🚀 Getting Started

1. Download `MeshalBox.ps1` from the repository.
2. Open PowerShell.
3. Run the script.
4. Browse the catalog and select the applications you need.
5. Start installing.
