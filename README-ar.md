# 📦 MeshalBox

**ثبّت برامجك المفضلة على Windows من مكان واحد.**

MeshalBox 
هو تطبيق لنظام Windows يتيح لك تصفح قائمة منظّمة من البرامج وتثبيت عدة تطبيقات دفعة واحدة باستخدام WinGet.

## ✨ المميزات

- 📚 **قائمة منظّمة** — تصفّح البرامج حسب التصنيف.
- ⚡ **التثبيت الجماعي** — ثبّت عدة برامج في عملية واحدة.
- 🪟 **دعم Windows** — مصمم للعمل على Windows 10 وWindows 11.
- 🛠️ **مبني باستخدام PowerShell** — يعتمد على PowerShell في تشغيل وظائفه.
- 📦 **التكامل مع WinGet** — يستخدم مدير الحزم الخاص بنظام Windows لتثبيت البرامج.
- 🚀 **نسخة تنفيذية محمولة** — شغّل ملف `.exe` مباشرةً دون الحاجة إلى تثبيت تقليدي.

## 📋 المتطلبات

- 🪟 نظام Windows 10 أو Windows 11.
- 📦 أداة WinGet (مدير الحزم لنظام Windows).

## 🚀 التحميل

- 📦 **[تحميل أحدث إصدار](https://github.com/iMeshall/MeshalBox/releases/latest)** — تنزيل ملف البرنامج التنفيذي الجاهز.
- 💻 **[الكود المصدري](https://github.com/iMeshall/MeshalBox)** — تصفح ملفات المشروع أو تنزيلها.

## 🖥️ طريقة التشغيل

### 📦 الخيار الأول: البرنامج التنفيذي

1. حمّل ملف `MeshalBox.exe` من [أحدث إصدار](https://github.com/iMeshall/MeshalBox/releases/latest).
2. شغّل الملف التنفيذي.
3. تصفّح قائمة البرامج واختر التطبيقات التي تريد تثبيتها.

### 💻 الخيار الثاني: تشغيل الكود المصدري

تأكد من وجود الملفين التاليين في المجلد نفسه:

- `MeshalBox.ps1`
- `applications.json`

بعد ذلك:

1. افتح PowerShell داخل مجلد المشروع.
2. شغّل السكربت باستخدام الأمر التالي:

   ```powershell
   .\MeshalBox.ps1
   ```

3. تصفّح قائمة البرامج واختر التطبيقات التي تحتاج إليها.
