# 📦 MeshalBox

**ثبّت برامج ويندوز المفضلة لديك من مكان واحد.**

MeshalBox أداة مكتوبة بملف PowerShell واحد، تتيح لك استعراض كتالوج منظّم من البرامج وتثبيت عدة تطبيقات دفعة واحدة باستخدام WinGet.

## ✨ المميزات

- 📚 **كتالوج منظّم** — استعرض البرامج حسب التصنيفات.
- ⚡ **التثبيت الجماعي** — ثبّت عدة برامج دفعة واحدة.
- 🪟 **دعم ويندوز** — مصممة للعمل على Windows 10 وWindows 11.
- 🛠️ **ملف PowerShell واحد** — الأداة موجودة في ملف سكربت واحد.
- 📦 **تكامل مع WinGet** — تستخدم مدير الحزم الرسمي من مايكروسوفت لتثبيت البرامج.

## 📋 المتطلبات

- 🪟 Windows 10 أو Windows 11
- 💻 PowerShell

## 🚀 طريقة الاستخدام

1. حمّل ملف `MeshalBox.ps1` من المستودع.
2. افتح PowerShell.
3. شغّل السكربت.
4. استعرض الكتالوج وحدّد البرامج التي تريد تثبيتها.
5. ابدأ عملية التثبيت.
